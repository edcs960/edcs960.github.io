여러 AI 코딩 도구로 실제 개발을 진행하는 로컬 작업대 **DevRoster**를 만들고 있습니다.

기획서 한 장에서 시작해 명세서와 화면 목업을 만들고, 사람이 승인한 범위 안에서만 AI가 코드를 고치게 한 뒤, 승인된 검증 명령으로 결과를 확인하고 게시하는 흐름을 하나의 앱으로 묶었습니다. Claude Code·Codex·Gemini CLI와 여러 API 모델을 같은 규칙으로 다룹니다.

이 블로그에는 DevRoster를 만들며 고민한 설계, 보안 점검과 수정, 여러 AI를 함께 쓰는 방법, 그리고 사용량·비용 관리 같은 기록을 시리즈로 정리합니다.
